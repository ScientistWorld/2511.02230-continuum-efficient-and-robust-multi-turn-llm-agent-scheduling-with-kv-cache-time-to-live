# Scientist Constraints

## Workloads

Scientists must evaluate on the deterministic workloads generated by `data/workloads.py` with the seeds, program counts, arrival rates, and turn multipliers used by `scripts/reproduce.sh`. Changing these settings changes the benchmark difficulty and can make improvements incomparable.

## Resource Model

Scientists must keep the simulator's request memory, prefill, reload, decode, and capacity settings fixed for reported scores. The paper's claim is about scheduling policy, not gaining by assuming a larger GPU or cheaper cache misses.

## Output Contract

Schedulers must write the same per-policy JSON artifacts consumed by `eval/evaluate_results.py`. Evaluation must remain independent from scheduler implementation code.

## External Data

No external traces or model measurements may be added to improve scores unless the full trace-generation and evaluation protocol is updated for every baseline and method in the same way.

## Compliance Checklist

- [ ] Uses the workload settings in `scripts/reproduce.sh`
- [ ] Keeps simulator memory and timing model fixed
- [ ] Writes compatible scheduler artifact JSON files
- [ ] Does not modify `eval/` to call method code
- [ ] Does not use extra traces or measurements for only one method
